# 三圈交集与策略取舍

## 何时读取

当三个圈已有初步信息，需要形成正式策略、比较多个机会或明确开发边界时读取。

## 策略逻辑链

```text
经营问题 → 市场机会 → 客户意愿 → 供应链承接 → 策略选择 → 产品方向 → 开发边界
```

每一步都要能回指上一环，不得从趋势直接跳到造型、口味、包装或工艺创意。

## 取舍顺序

1. 先排除三圈不重叠的方向；
2. 再比较消费者价值、渠道价值和客户经营任务；
3. 再比较投入负担、复杂度、稳定性和验证成本；
4. 说明为什么选择当前方向，以及放弃了什么；
5. 写出最小验证动作和退出条件。

## 输出状态

- `recommended`：三圈交集清晰，可进入用户策略确认；
- `conditional`：方向有价值，但必须先完成具体验证；
- `pending`：证据不足，只能列为待研究；
- `not_recommended`：结构性冲突，不进入当前开发。
